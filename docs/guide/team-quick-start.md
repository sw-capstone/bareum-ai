# AI 저장소 빠른 시작

## 작업 순서

1. GitHub 이슈를 생성한다.
2. `develop`을 최신화하고 작업 브랜치를 만든다.
3. AI 코드·테스트 또는 문서를 작업한다.
4. 필요하면 로컬 하네스를 실행한다.
5. Push 후 Pull Request를 생성한다.
6. GitHub Actions 결과와 리뷰를 확인한다.
7. 승인 후 팀 규칙에 따라 병합한다.

## 검사 명령

```bash
./scripts/run-harness.sh check
./scripts/test-harness.sh
```

로컬 실행은 선택 사항이며 PR에서는 CI 결과를 확인한다. 현재 하네스는 저장소 구조와 문서를 검사하고 AI 기능의 정확성·성능은 검사하지 않는다.

## 담당자 역할

- AI 담당자: AI 기능, 테스트, 평가 기준과 영역별 검사를 작성한다.
- 하네스 담당자: 검사 기준·정책·실행 명령·CI 연결을 리뷰한다.
- 계약 변경 담당자: 서버 담당자와 형식을 합의하고 영향받는 구현과 테스트를 함께 수정한다.

하네스 변경 PR에는 하네스 담당자를 필수 리뷰어로 지정한다.
