# RMA 재실행 일치도 근거 (2026-10-14)

**최신 측정:** 매뉴얼에 따라 목차 적용 조건을 명시한 D1–D2의 Move·Step 조합 일치도는 **552/602 = 91.6944%**다. 목차 선택은 두 실행에서 문서별로 일치했다(기획 2편·행사교육 2편). 아래 A·B·C 결과는 이전 버전의 기록이며, 현재 버전은 「목차 적용 조건 보완 후 신규 측정」을 따른다.

## 보완 전 기록

기존 PR의 ‘약 93%’를 저장된 실행 결과로 재계산했다. 기본 지시문 A1–A2의 **Move·Step 조합 일치도는 562/602 = 93.3555%**다. 검토 기준 31개의 점검은 원본 A판 2편 기준이고, 이 일치도는 보고서 2쌍의 A/B 판본 **4편** 기준이다. 원본 검토 기록에는 B판이 의도치 않게 포함되었다고 적혀 있다. 문서 4편을 독립 표본 4개로 해석하면 안 된다.

이 수치는 확정 정답에 대한 정확도, 사람 간 일치도 또는 전체 라벨의 완전 일치율이 아니다. 당시 계산 스크립트는 발견하지 못했으나 화면의 Move·Step 비교 방식과 같은 정의를 적용해 보고된 93%와 예시판의 89%를 재현했다. 아래 산식을 이번 재계산의 명시적 정의로 사용한다.

## 산식과 포함 범위

동일한 입력과 설정으로 두 번 실행한 뒤, 각 블록·표 행에 붙은 Move와 Step 조합이 모두 같은지 비교한다. 최신 측정에서는 602개 단위 중 552개가 같아 91.69%다. Move가 같아도 Step이 다르거나 라벨이 하나라도 추가·누락되면 해당 단위는 불일치로 센다. 두 실행 모두 라벨이 없는 단위도 일치에 포함하며, 정답 여부나 근거 문구의 일치까지 확인하는 수치는 아니다.

각 단위를 `(document_id, block_id, row)`로 식별한다. 일반 블록의 row는 null, 표는 출력의 행 번호다.

```text
signature(unit) = sort([(move, sort(step names)) for each annotation])
N = 두 실행에 나타난 단위 키의 합집합 크기
M = 양쪽에 존재하고 signature가 같은 단위 수
agreement = M / N
```

- annotation 및 Step의 나열 순서는 무시하되 중복 개수는 유지한다.
- 일반 블록의 빈 annotations와 표의 열 제목·빈 행도 단위에 포함한다. 빈 목록끼리도 일치다.
- 한쪽에만 있는 단위는 불일치다. 양쪽 모두 출력하지 않은 블록 및 rows가 없는 not_targeted/unreadable 표는 포함하지 않는다.
- 근거 구절·위치, 주 기능, SPEC 항목·값, 판정 사유·상태, 표 행 역할, 문서 유형·주제·목차는 비교하지 않는다.
- 문서별 비율을 평균하지 않고 모든 단위의 M과 N을 합산한다. 긴 문서의 영향이 크다.
- 실패 단위가 있거나 미완료인 실행, 문서 집합·파싱 해시·모델 설정·프롬프트·명세·재시도 정책이 다른 실행은 비교 도구에서 거절한다.
