# AI 하네스 확장 로드맵

적용 문서: `harness-v1.4`

이 문서는 순차적인 단계가 아니라 실제 작업에 따라 선택하는 검사 추가 기준이다. 구현·계약·평가 자산과 통과 기준이 확정된 경우에만 해당 항목을 적용한다.

## 현재 운영 항목

- 필수 경로 검사
- JSON 문법 검사
- Markdown 내부 링크 검사
- 비밀정보 의심 패턴 검사
- 검사기 자체 테스트와 GitHub Actions 실행
- JSON 리포트 아티팩트 제공

## AI 실행 코드가 추가될 때

- 기술 스택의 포맷·린트·타입 검사
- 단위·통합 테스트 실행 명령
- 실패 시 CI 종료 조건
- 의존성 및 실행 환경 재현 방법

## 모델·프롬프트·규칙이 추가될 때

- 모델·프롬프트·규칙 버전 기록
- 입력·출력 형식 검증
- 승인되지 않은 자산 사용 방지
- 실행 결과와 Git SHA 추적

## 평가 데이터가 추가될 때

- 데이터 형식과 필수 메타데이터 검사
- 평가셋 버전과 사용 권한 확인
- 기준 결과와 성능 회귀 검사
- 판단보류·실패 사례 포함 여부 확인

## 서버 계약이 확정될 때

- 서버↔AI 요청·응답·오류 Schema 검사
- 제공자·소비자 호환성 검사
- 계약 버전과 관련 PR 연결

## 실제 연동 환경이 준비될 때

- 핵심 성공 흐름
- 시간 초과와 오류 전달
- 사용한 서버·AI Git SHA와 계약 버전 기록
- 릴리스 후보의 핵심 전체 흐름 검사

각 검사는 영역 담당자가 정상·경계·실패 사례와 함께 작성하고 하네스 담당자의 리뷰를 받는다. 하네스가 제품 코드나 판정 기준을 임의로 생성하지 않는다.
