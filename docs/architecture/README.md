# 아키텍처 문서

- [`repository-boundaries.md`](repository-boundaries.md): 레포 간 책임과 의존 방향
- [`repository-structure.md`](repository-structure.md): 현재 확정된 레포 구조

현재 확정된 내용은 `bareum-web`과 `bareum-server`의 레포 경계뿐이다. 백엔드와 AI의 모듈·코드 경로·실행 단위·배포 방식은 아직 결정하지 않았으므로, 이를 전제로 한 하위 아키텍처 문서와 디렉터리는 두지 않는다. 해당 결정이 완료되면 결정 기록과 구현을 함께 추가한다.

구체 구현은 각 레포의 `AGENTS.md`, 계약, 결정 기록과 하네스 기준 문서를 함께 따른다. GitHub 협업 방식은 [노션 협업 규칙 문서](https://app.notion.com/p/3d804af60ca8802480d3e7d65a29b5dd)를 기준으로 한다.
