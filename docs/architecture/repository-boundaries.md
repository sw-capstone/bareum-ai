# AI 저장소 책임 경계

## 저장소별 책임

| 저장소 | 책임 |
| --- | --- |
| `bareum-web` | 화면과 서버 공개 API 소비 |
| `bareum-server` | 백엔드 공개 API, 서버 상태와 공유 계약 |
| `bareum-ai` | AI 처리 코드, AI 전용 테스트와 평가 |

웹은 AI 저장소를 직접 호출하지 않는다. 서버가 AI 처리를 호출하고 공개 API 형태로 웹에 결과를 제공한다.

## 계약 경계

서버↔AI 입력·출력·오류·시간 초과 형식은 담당자가 합의한 뒤 `bareum-server/packages/contracts/`에서 관리한다. AI 저장소는 해당 계약을 사용하는 구현과 테스트를 관리하며 서버 계약 파일을 복제하지 않는다.

계약이나 실제 연동 검사가 추가되기 전에는 서버 또는 웹 검사가 AI 검증을 대신하지 않는다.
