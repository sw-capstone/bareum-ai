# 데이터 분할

평가 데이터셋 구축에 사용하는 원본 보고서 분할이다. 분할 결과는 [`manifest.json`](manifest.json)을 기준으로 한다.

- 분할 단위: 파일명 기준 A/B 보고서 쌍. 쌍은 나누지 않는다.
- 고정 seed: 42, 요청 비율: 30 / 35 / 35
- 파일 경로는 원본 PDF 루트 기준이며, 원본 PDF는 저장소에 포함하지 않는다. 각 파일은 `sha256`으로 식별한다.
- `test_excluded_groups`: 기획 문서에서 인용되어 Test에서 제외한 보고서 쌍

| 분할 | 쌍 | 문서 | 용도 |
| --- | ---: | ---: | --- |
| `dev` | 30 | 60 | 규칙 적용 기준·생성 방법·검증 방법 개발 |
| `test` | 30 | 60 | 기준 고정 후 평가셋 구성 |
| `cbr` | 26 | 52 | 사례 참조용 |
| 합계 | 86 | 172 | |

파싱 결과와 합성 파생본은 원본의 분할을 그대로 따른다.
