# 하네스 지침

- 개발 과정 검사와 제품 AI 평가를 혼합하지 않는다.
- 각 검사는 `HAR-*` 고유 ID, 입력, 판정 조건, 실패 메시지와 테스트를 갖는다.
- ID 발급과 변경은 `docs/decisions/DEC-ID-001-id-governance.md`를 따른다.
- 정답셋·통과 기준·권한을 낮추는 변경은 결정 기록과 검토를 요구한다.
- 모델·프롬프트·룰셋·선택된 기준 데이터 snapshot·Git SHA를 결과에서 역추적할 수 있게 한다.
- 미실행 검사를 통과로 기록하지 않고 `미수행` 또는 `판단보류`로 구분한다.
- 제품 규칙 ID는 공식 카탈로그가 승인된 뒤 그 체계를 사용하고 프로젝트 자산 ID와 분리한다. 승인 전에는 ID나 규칙을 추정해 추가하지 않는다.
- 제품 AI 기능이 확정되어 실제 구현될 경우에도 RMA는 검사 위치와 라우팅만 담당하고, CBR은 확정된 이슈의 수정 보조만 담당한다. 현재는 해당 기능이나 책임 경계를 구현 기준으로 확정하지 않는다.
