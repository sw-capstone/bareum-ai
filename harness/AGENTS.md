# AI 하네스 작업 지침

- 현재 검사 범위는 필수 경로, JSON 문법, Markdown 링크와 비밀정보 의심 패턴이다.
- 새 검사는 실제 AI 구현·계약·평가 자산과 통과 기준이 확정된 작업에서 추가한다.
- 영역 담당자가 검사와 정상·실패 사례를 작성하고 하네스 담당자를 필수 리뷰어로 지정한다.
- 각 검사는 `HAR-*` ID, 입력, 판정 조건, 실패 메시지와 자체 테스트를 갖는다.
- 하네스는 제품 코드를 대신 작성하거나 AI 결과의 사실성을 자동 확정하지 않는다.
- 다른 저장소의 파일을 상대 경로로 직접 참조하지 않는다.
- `not_applicable`과 `disabled` 상태가 필요한 검사가 생기면 의미와 처리 방법을 문서에 함께 추가한다.
